# 使用记录、反馈与前后对比

## 使用记录

- 文献检索：按关键词检索本地文献库和开放学术资源。
- 原文阅读：打开论文内容、PDF 和图表资源。
- 证据核对：从检索结果回到论文内容和原文位置。
- 报告生成：根据研究目标、文献内容、计算结果和图表生成报告。

## 项目组反馈

- 支撑材料减少平台概念介绍，改为已有文件和界面证据索引。
- 文献工作台保留 9 月提交版本的 Molyte 原版。
- 电池内容放到最后，只作为应用案例。
- 现有报告案例直接作为配套材料，不重新编写案例结论。

## 前后对比

| 内容 | 整理前 | 整理后 |
|---|---|---|
| 材料组织 | 作品说明、案例、截图和代码分散 | PDF 统一索引，ZIP 统一保存附件 |
| 文献界面 | 新旧界面截图混用 | 统一使用原版 Molyte 文献工作台 |
| 案例呈现 | 通用能力和电池案例交叉出现 | 先讲通用模块，最后给出电池案例 |
| 报告材料 | 报告案例单独保存 | 在 PDF 中索引，并放入 ZIP |
